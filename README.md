# 指纹浏览器如何迁移到新电脑？

从旧电脑迁到新电脑时，**「指纹浏览器」** 可以先用一个测试环境验收同步。给它取个容易辨认的名字，加一个测试书签，再下载一份样例文件。新电脑上分开核对这三样，就知道哪些已经同步、哪个文件还得另行复制。

## 原电脑上先做三件事

1. 在指纹浏览器打开「账号与同步」，核对登录账号、登录方式和同步状态。若同步失败，先恢复网络并重试。
2. 记下测试环境的设备设置、分组及书签名称。下载的样例文件单独记下保存路径。
3. 正常关闭该环境。保留旧电脑原状，等新电脑逐项核对完成再按交接流程处理。[官方换设备教程](https://zwbrowser.com/help/desktop/sync/)

![从旧电脑确认账号和同步状态](https://zwbrowser.com/images/help-desktop-sync.webp)

## 新电脑上按数据类型验收

| 在新电脑检查 | 看到什么才能勾选 |
| --- | --- |
| 工作台 | 能找到原测试环境，名称与分组对应 |
| 环境配置 | 已记录的设备信息与原电脑相符 |
| 书签 | 测试书签能从书签列表打开 |
| 网站身份 | 可用自己的授权账号访问，必要时重新验证 |
| 下载目录 | 需要保留的文件已通过团队批准的方式另行传递 |

如果「环境出现了，但网站要求登录」，先核对环境和网址，再用平时的方式完成网站验证。业务网站可以让会话过期。无需为了证明迁移成功而导出真实账号凭据。验收结果里分别记录「环境已恢复」与「网站已重新登录」即可。
